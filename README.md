<details>
<summary>🐍 Commit Graph (contribution snake) — optional, one-time setup</summary>
<br>

This turns your contribution grid into an animated snake that "eats" your squares. It needs a small GitHub Action added to your **`khanuzair-f15/khanuzair-f15`** repo (the one this README lives in) since it has to run on a schedule and commit its output.

**Steps:**
1. In this repo, create the file `.github/workflows/snake.yml` with:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"   # once a day
  workflow_dispatch:        # lets you trigger it manually too

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        id: snk
        with:
          github_user_name: khanuzair-f15
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

2. Go to the **Actions** tab of the repo and run "Generate Snake" once manually (`workflow_dispatch`) so it creates the `output` branch.
3. Then add this to your README wherever you'd like it to appear:

```md
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/khanuzair-f15/khanuzair-f15/output/dist/github-snake-dark.svg" />
  <source media="(prefers-color-scheme: light)" srcset="https://raw.githubusercontent.com/khanuzair-f15/khanuzair-f15/output/dist/github-snake.svg" />
  <img alt="github contribution snake animation" src="https://raw.githubusercontent.com/khanuzair-f15/khanuzair-f15/output/dist/github-snake.svg" />
</picture>
```

It'll re-run daily on its own after that. Full docs/troubleshooting: [Platane/snk](https://github.com/Platane/snk).
